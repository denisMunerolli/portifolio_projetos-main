Principais Projetos em Engenharia de Software

Projeto de Fraudes em Transações Bancárias

Desenvolvi um projeto de detecção de fraudes em transações bancárias utilizando Java, HTML, CSS, JavaScript e banco de dados, totalmente integrado no Eclipse IDE. A aplicação realiza análise de dados transacionais, identifica padrões suspeitos com base em regras de negócio, e sinaliza possíveis fraudes de forma automatizada. Trabalhei desde a construção do back-end com Java até o front-end com interfaces web, além de toda a lógica de validação, persistência e manipulação dos dados. O projeto teve como foco aumentar a segurança e reduzir riscos operacionais por meio de tecnologia acessível e aplicável a cenários reais.

No projeto, foi desenvolvida uma aplicação web que permite um acesso fácil e integrado ao modelo em produção, tornando as previsões disponíveis para qualquer consumidor a qualquer momento.

As ferramentas utilizadas foram:

  • Java 17 e Eclipse IDE
  • Regras de negócio aplicadas para identificação de padrões anômalos em transações
  • HTML5, CSS3 e JavaScript puro para construção do front-end
  • Banco de dados relacional com JDBC para persistência e consulta eficiente
  • Servlets e JSP para controle de fluxo e integração entre camadas
  • Git e GitHub para controle de versão e colaboração
  • Integração completa entre front-end, back-end e banco de dados

Fraud Detection: Modelo de detecção de fraude em transações bancárias

O modelo utiliza técnicas de Machine Learning para identificar transações suspeitas com base em padrões anômalos. Ele é alimentado por uma base histórica de transações legítimas e fraudulentas, e toma a decisão calculando o risco associado a cada transação, aumentando a segurança e diminuindo o risco de perdas financeiras.

As ferramentas utilizadas foram:

  • Linguagem: Java
  • Manipulação e Tratamento de Dados: JDBC, SQL
  • Machine Learning: Random Forest, SVM, e outros algoritmos de detecção de anomalias
  • IDE: Eclipse IDE
  • Visualização: Matplotlib, Tableau (para análise de resultados)

Fraud Detection: Modelo de detecção de fraude em transações bancárias (continuação)

Além de Machine Learning, o modelo inclui validação cruzada e outras técnicas para garantir a precisão das previsões, além de aplicar um monitoramento contínuo para a adaptação a novos padrões fraudulentos.
